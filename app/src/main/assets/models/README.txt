Place your auto_rickshaw.glb file in this directory:
app/src/main/assets/models/auto_rickshaw.glb

The app's GlbModelLoader will automatically detect and load your binary GLB 2.0 3D model!
If no file is present, the app renders the built-in high-fidelity Kerala Auto-Rickshaw model matching the Sketchfab low-poly auto-rickshaw geometry.
